# Simple Issue Tracker

[한국어](#korean)

A desktop app for Simple Issue Tracker, for macOS and Windows.

- Enter a server address to connect. You can register several servers and switch between them, and the app brings back what you had open when you start it again.
- Stays in the menu bar (tray) and runs AI agents on this computer.
- To use it on your own with no server, install the [Standalone](https://github.com/TypoStudio/issue-tracker-standalone) add-on from the app (Apple Silicon on macOS, x64 on Windows).

## Download

The latest version is on the [Releases](https://github.com/TypoStudio/issue-tracker-desktop/releases/latest) page. Direct links for 0.3.1:

- macOS (Apple Silicon and Intel, 10.15 or later): [Simple-Issue-Tracker_0.3.1_macOS_universal.dmg](https://github.com/TypoStudio/issue-tracker-desktop/releases/download/v0.3.1/Simple-Issue-Tracker_0.3.1_macOS_universal.dmg)
- Windows (x64): [Simple-Issue-Tracker_0.3.1_Windows_x64-setup.exe](https://github.com/TypoStudio/issue-tracker-desktop/releases/download/v0.3.1/Simple-Issue-Tracker_0.3.1_Windows_x64-setup.exe)

Once installed, the app checks this repository for updates and verifies each download's signature before installing it.

### First launch

The installers are not notarized by Apple or code-signed for Windows, so you'll see a warning.

- **macOS**: the app is blocked the first time you open it. Go to **System Settings > Privacy & Security**, scroll down, and click **Open Anyway**.
- **Windows**: when "Windows protected your PC" appears, click **More info**, then **Run anyway**.

# 한국어

이슈트래커를 쓰는 데스크톱 앱입니다. macOS 와 Windows 에서 실행됩니다.

- 서버 주소를 입력해 이슈트래커에 연결합니다. 여러 서버를 등록해 전환하며 쓸 수 있고, 다시 실행하면 열려 있던 화면을 복원합니다.
- 메뉴바(트레이)에 상주하며 이 컴퓨터에서 AI 에이전트를 실행합니다.
- 서버 없이 혼자 쓰고 싶다면 [단독버전](https://github.com/TypoStudio/issue-tracker-standalone) 추가기능을 앱에서 설치할 수 있습니다(macOS 는 Apple Silicon 만, Windows 는 x64).

## 내려받기

최신 버전은 [Releases](https://github.com/TypoStudio/issue-tracker-desktop/releases/latest) 에 있습니다. 0.3.1 바로 받기:

- macOS (Apple Silicon·Intel, 10.15 이상): [Simple-Issue-Tracker_0.3.1_macOS_universal.dmg](https://github.com/TypoStudio/issue-tracker-desktop/releases/download/v0.3.1/Simple-Issue-Tracker_0.3.1_macOS_universal.dmg)
- Windows (x64): [Simple-Issue-Tracker_0.3.1_Windows_x64-setup.exe](https://github.com/TypoStudio/issue-tracker-desktop/releases/download/v0.3.1/Simple-Issue-Tracker_0.3.1_Windows_x64-setup.exe)

설치한 뒤에는 앱이 이 저장소에서 업데이트를 확인하고, 내려받은 파일의 서명을 확인한 뒤 설치합니다.

### 처음 실행할 때

설치 파일이 Apple 공증과 Windows 코드 서명을 받지 않아 경고가 나옵니다.

- **macOS**: 앱을 처음 열면 차단됩니다. **시스템 설정 > 개인정보 보호 및 보안** 맨 아래에서 **그래도 열기**를 누릅니다.
- **Windows**: "Windows의 PC 보호" 창이 나오면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.
